# NetCat

NetCat — portable-приложение для Windows, объединяющее VPN, маршрутизацию и Zapret.
Для подключения нужен собственный VPN-профиль или подписка; серверы не предоставляются.

## Возможности

- Профили sing-box и Xray: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC и Naive.
- TUN и правила для приложений, доменов и IP-адресов.
- Проверки подключения и передачи данных, мониторинг и автосмена профилей.
- OpenVPN для корпоративной сети независимо от основного VPN, Zapret и Telegram WS proxy.
- Обновление подписок и модулей, автозапуск и работа в системном трее.

## Требования

Windows 10/11 x64. Для TUN, маршрутов и Zapret нужны права администратора.

## Установка

Скачайте `NetCat-v1.0.4-win-x64.zip` из [Releases](https://github.com/akapustyanik/NetCat/releases),
распакуйте в отдельную папку и запустите `NetCat.exe`.

## Обновления

Архивы проверяются по SHA256 и подписанному Ed25519-манифесту.
EXE подписан собственным сертификатом NetCat. Windows не доверяет ему по умолчанию
и может показать предупреждение. Для автоматической установки обновлений откройте
«Настройки → Обновления NetCat», сверьте отпечаток сертификата, нажмите
«Доверять сертификату NetCat» и включите автоустановку. Доверие добавляется только
для текущего пользователя Windows; его можно удалить там же.
Кнопка «Обновить выбранные» скачивает, проверяет и устанавливает обновления за один шаг.
При обновлении приложения NetCat сам кратковременно останавливает подключения,
перезапускается и восстанавливает их. Настройка восстановления при обычном запуске
не изменяется. Автоустановка ждёт завершения текущих операций и тестов.
NetCat должен работать с правами администратора. Для перехода с неподписанных
1.0.0/1.0.1 распакуйте 1.0.2 вручную: их updater не принимает неподписанную исходную сборку.

SHA256 сертификата: `DF65D213985F781F2732E12847C176B761BEB2FEFC720328181F339EC466A42A`.
