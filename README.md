# NetCat

NetCat — приложение для Windows, которое объединяет VPN и Zapret в одном интерфейсе. Обычный трафик можно отправлять через VPN, а отдельные сервисы и приложения — напрямую через Zapret.

## Возможности

- VPN через **sing-box / Xray** с поддержкой TUN.
- Правила маршрутизации для приложений, доменов и сервисов.
- **Zapret / Flowseal** для YouTube и Discord.
- OpenVPN, проверка профилей, автоматическое переключение и обновление модулей.

## Установка

1. Откройте раздел **Releases** и скачайте последнюю сборку для Windows x64.
2. Распакуйте ZIP в отдельную папку.
3. Запустите `NetCat.exe`.

NetCat — portable-приложение, установка не требуется. Для управления TUN, маршрутами и Zapret нужны права администратора.

> NetCat не предоставляет VPN-серверы или подписки. Для VPN нужен собственный профиль или подписка.

## Первый запуск

Импортируйте VPN-профиль или подписку, выберите нужный профиль и включите VPN.
На вкладке **Zapret** можно отдельно направить YouTube и Discord через Zapret, оставив остальной трафик в VPN.

Поддерживается **Windows 10/11 x64**.

## Beta

`1.0.0-beta` — публичная beta-версия. Если что-то работает неправильно, создайте Issue и приложите описание проблемы и логи NetCat без приватных данных.

Если Windows показывает предупреждение SmartScreen, убедитесь, что архив скачан именно из раздела Releases этого репозитория, и сверьте SHA-256 с контрольной суммой релиза.

## Используемые проекты

NetCat использует сторонние open-source компоненты, включая:

- [sing-box](https://github.com/SagerNet/sing-box)
- [Xray-core](https://github.com/XTLS/Xray-core)
- [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
- OpenVPN и Wintun

Лицензии и сведения о сторонних компонентах находятся в `THIRD_PARTY_NOTICES.md`.
