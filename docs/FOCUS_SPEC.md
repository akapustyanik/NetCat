# NetCat Focus — согласованное направление и уточнения

Основание: выбор пользователем варианта 02 Focus и уточнения функций, 2026-09-12. Здесь сохраняются требования к реализации. Текущий результат — нативная предварительная сборка `artifacts/NetCat-Test-02`; реализованные возможности и ограничения описаны в README.md. Исторические интерактивные макеты сетевых операций не выполняют.

## Общий интерфейс

Верхняя навигация: Подключение, Профили, Маршрутизация, Zapret, Модули, Настройки и Журнал. На главном экране — круглая кнопка, состояние, выбранный профиль, показатели сессии и компактные сервисы. На страницах настроек используется вся доступная ширина окна; главный экран остаётся компактным. Пользователь отдельно выбирает основной и акцентный цвета на градиентной палитре; готовые оттенки сохраняются. Нативный WPF, единая тема главного окна, диалогов, карточек и прокрутки.

## Профили и импорт

- Видимая кнопка «Импорт»: URL подписки, отдельные URI, текст JSON и `.ovpn`, выбор файлов. Поддерживать VLESS, VMess, Shadowsocks, Trojan, Hysteria2, TUIC и OpenVPN согласно ТЗ. Форматы подписок определять по содержимому, а не только расширению: plain URI list, Base64 list, поддерживаемые JSON-конфигурации. Неподдерживаемые поля не отбрасывать молча.
- Перед добавлением — предпросмотр распознанных профилей, ошибки по элементам, выбор добавляемых записей и обработка дубликатов. Пустой/HTML/ошибочный ответ не считать импортом.
- Подписку можно переименовать, обновить вручную и по расписанию; сохранять локальные назначения ролей и изменения согласно выбранной политике обновления. Невалидный ответ не удаляет рабочие профили.
- Предоставленную пользователем ссылку считать личным источником. Не сохранять полный адрес в документации, публичном Git, релизах или диагностике. Для макетов использовать example.invalid. Реальное получение содержимого относится к реализации импорта, а не демонстрации интерфейса.
- Редактирование: имя, адрес, порт, целевое ядро, параметры протокола, транспорта/TLS/Reality, исходный конфиг с валидацией. Секреты скрыты по умолчанию. Сохранение блокируется при несовместимом ядре/протоколе.
- Каждый профиль имеет действие «Подключить»/«Отключить», тест и настройку участия в автосмене. Отдельные роли основного/резервного при необходимости.
- OpenVPN — полноценный подключаемый профиль: импорт `.ovpn` и связанных сертификатов/ключей, параметры аутентификации, состояние запуска, остановка, ошибки. Не показывать готовность только по наличию openvpn.exe. Без явного выбора не исполнять директивы подключения внешних скриптов из импортированного профиля.
- Ручной тест одного/выбранных/всех профилей; показатели TCP RTT, HTTP через проверяемый профиль, потери, время измерения. Скорость и доступность профиля не выводить из ping хоста. OpenVPN проверять через реальный поднятый туннель с очисткой ресурсов после теста.
- **Автотест и автосмена независимы.** Автотест: включение, интервал, таймаут, адрес проверки. Автосмена: отдельный выключатель, пул кандидатов, порог последовательных ошибок и стабилизация против частых переключений. При выключенной автосмене профиль остаётся выбранным даже при неудачном тесте; показывается причина ошибки. Нажатие «Отключить» не запускает повторное автоматическое подключение.

## Маршрутизация

- Единый упорядоченный список вместо нескольких огромных пустых панелей: включение правила, условие, маршрут, приоритет, редактирование и удаление. Первое подходящее активное правило определяет маршрут.
- Условия: точное имя процесса, полный путь EXE, выбор работающего приложения (имя/PID/путь), точный домен/домен с поддоменами, IP/CIDR, набор доменов или адресов. Расширенные условия — порт/диапазон, TCP/UDP; условия в одной записи соединяются AND, список значений одного поля — OR. Возможности генератора должны соответствовать проверенной версии ядра.
- Действия: напрямую, основной VPN, конкретный профиль (включая OpenVPN), блокировать. Zapret — обработка прямого трафика отдельным модулем, а не VPN outbound. Telegram MTProto — отдельное приложение/соединение, не универсальный маршрут для произвольных доменов.
- Выбор общего режима: по правилам, весь трафик через VPN, только выбранное через VPN, всё кроме выбранного через VPN. Видно, какие правила действуют в режиме и куда пойдёт трафик без совпадения; настройки других режимов сохраняются.
- Быстрые действия: «Добавить EXE», «Из запущенных», домен/URL, IP/подсеть; импорт списков, включая domains.lst, и пресеты RU/реклама. Источник и версия rule-set должны быть известны; не выдавать небольшой пример за полноценную геобазу.
- Предпросмотр нормализованного домена при вставке URL. При вводе пути URL объяснять, что доменные правила применяются ко всему хосту, а не конкретному пути HTTPS.
- Кнопки «Применить» и «Отменить изменения», счётчик несохранённых изменений, предупреждение о перекрывающихся правилах и недоступном целевом профиле. Конфигурация проверяется до замены рабочей, при ошибке сохраняется предыдущая.
- «Проверить маршрут»: домен/IP, приложение и при необходимости порт/протокол → совпавшее правило, действие и причина. Это объяснение правил; реальное сетевое соединение проверяется отдельной диагностикой.
- OpenVPN для отдельных приложений/доменов требует настоящей изоляции маршрутов/интеграции с основным маршрутизатором. До реализации показывать явную недоступность, не имитировать поддержку кнопкой.

## Zapret

- Получать весь совместимый комплект из Flowseal/zapret-discord-youtube. Отображать конфиги с естественной сортировкой ALT1, ALT2, …, ALT10.
- Отдельно отображать выбранную для просмотра стратегию и реально работающую. «Применить» запускает выбранную; можно остановить модуль.
- «Тест выбранной» и «Автотест»: последовательный перебор стратегий, прогресс, отмена, результаты по целям (YouTube/Discord и настраиваемый список), ошибки/таймауты и время проверки. Для Discord отдельно различать HTTP-доступность и голос/UDP, если последний действительно проверяется.
- Тест идёт через прямое соединение с Zapret, а не через VPN, иначе результат недостоверен. Исключать влияние системного прокси и маршрутов VPN; при невозможности изоляции сообщать об ограничении.
- Во время проверки не запускать конфликтующие экземпляры winws. После теста/отмены/сбоя возвращать предыдущую стратегию и предыдущее состояние остановленного модуля.
- Ранжировать по успешным проверкам и задержке. Показывать предложение лучшей стратегии; применять автоматически только при включённой отдельной настройке «Применить лучший результат». Автотест не означает согласие на постоянную автосмену.
- Обновление конфигов не сбрасывает рабочий выбор без сообщения; удалённая upstream стратегия помечается недоступной.

## Приёмка функциональной реализации

1. Импорт личной подписки с предпросмотром; ошибки не создают фиктивные профили, секрет не попадает в лог.
2. Редактирование профиля сохраняется после перезапуска, несовместимые параметры выявляются до запуска.
3. OpenVPN действительно подключается/останавливается; проверены авторизация, маршруты и очистка после ошибки.
4. EXE/домен/CIDR правила применяются в заданном порядке, обход/блокировка/выбор профиля подтверждены реальным трафиком.
5. При работающем автотесте и выключенной автосмене активный профиль не меняется; при ручном отключении не происходит переподключение.
6. Автотест Zapret показывает результаты проверяемых стратегий, отменяется и восстанавливает прежнее состояние.
7. Светлая/тёмная темы, клавиатура, масштаб Windows 100/150/200%, пустые/ошибочные состояния и небольшое окно остаются удобными.

До прохождения этих проверок результат обозначается как макет или предварительная сборка, а не готовая реализация сетевых функций.
