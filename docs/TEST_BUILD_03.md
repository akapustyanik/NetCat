# Тестовый билд 03

Запуск: `artifacts/NetCat-Test-03/NetCat.exe`. Перед запуском завершите прежний экземпляр через трей. Сохранённые настройки и профили используются из прежнего каталога пользователя. Для запуска нужны соседние DLL и папка `bin`.

- Zapret: пиксельная прокрутка с переходом 160 мс, накоплением движения колеса, сохранением выделения. Перетаскивание ползунка и клавиатура останавливают анимацию. Учитываются настройки прокрутки и отключения анимации Windows.
- Профили, правила и компоненты обновления: скруглённые карточки, единые отступы и выделение. Для пустых списков есть подсказки. В модулях показаны назначение, версии и состояние; флажки установки доступны для незакреплённых обновлений.
- Навигация размещена в строке заголовка с небольшим отступом сверху и большим снизу.
- Вместо времени сессии отображается пинг: время HTTP-ответа до адреса теста из настроек через работающий SOCKS-порт NetCat, по текущим правилам маршрутизации. Это не ICMP-пинг и не обязательно маршрут основного VPN, если для адреса теста задано исключение. Проверка каждые 10 секунд, таймаут 4 секунды; без подключения — прочерк, при ошибке — «Нет ответа». Дополнительные ядра не запускаются, интерфейс не блокируется.

Подтверждено: 40 автоматических тестов, сборка и успешный запуск итогового EXE. Проверка интерфейса: изолированный запуск WPF и отрисовка экранов в светлой, тёмной и красной теме. Smoke-проверка измеряет промежуточный и конечный сдвиг прокрутки и сохранение выделения. Демонстрационные строки на снимках создаются только в изолированном smoke-режиме.

Без ZIP, установщика и публикации релиза. Сетевые профили и корпоративное подключение в рамках визуальных изменений повторно не проверялись.
