# Тестовый билд 12 — исправление обработки стратегий Zapret

Версия: 0.5.0-test.12. EXE: `artifacts/NetCat-Test-12/NetCat.exe`.

## Что найдено

В билде 11 NetCat заменял все положительные списки доменов в отдельных профилях стратегии одним общим списком сценария и удалял положительные IP-фильтры. Это изменяло смысл BAT-файла: ранний профиль для Google перехватывал также обычные домены Discord, и до предназначенного для них обработчика дело не доходило. Проверка `--dry-run` подтверждала корректность синтаксиса, но не могла выявить это изменение поведения.

В сохранённых настройках старой v0.4.0 выбрана `general (ALT10).bat`, в новой версии на момент диагностики — `general (ALT).bat`. Файл ALT10 в обоих комплектах имеет одинаковый SHA-256. Сравнивать работу версий следует с одной и той же стратегией.

На момент чтения текущих настроек и `runtime/router.json` оба сервиса были направлены через VPN. Отдельные запросы к странице YouTube и API Discord gateway через существующий SOCKS-вход 10808 получили HTTP 200. Это не проверяет Zapret, воспроизведение видео или голосовую связь. HTTP-пинг приложения также проверяет VPN-профиль, а не доступность этих сервисов через Zapret.

## Исправления

- Для каждого профиля стратегии сохраняется пересечение его исходных доменов с выбранными сервисами. Сохраняются порядок профилей, точные домены с `^`, исключения, параметры обработки и положительные IP-фильтры. Пустой профиль исключается, чтобы он не стал безусловным.
- Специальный профиль `discord.media` больше не расширяется на все сервисы. Голосовой профиль Discord/STUN остаётся без ограничения по HTTP Host/SNI. Встроенный список Google содержит также `stable.dl2.discordapp.net`: это исключение сохранено в соответствии с исходной стратегией.
- Профили без собственных доменных ограничений дополнительно ограничены сценарием. Для IP-профилей применяется одновременно исходный IP-фильтр и список выбранных сервисов; обработка постороннего трафика не расширяется.
- Zapret получает `--wf-iface` с индексом выбранного физического адаптера. Он обрабатывает физический выход, а не внутреннюю сторону NetCat-TUN, где изменение TLS/QUIC может мешать анализу и маршрутизации sing-box. Индекс и название адаптера выводятся в журнал запуска.
- Общие списки маршрутизатора и Zapret дополнены доменами YouTube API, встроенного проигрывателя, изображений, загрузок и вложений Discord из комплектных списков Flowseal.

## Проверки и ограничения

Добавлены регрессионные проверки разделения Google/Discord для всех комплектных стратегий в трёх сценариях, сохранения IP-фильтров, точных доменов и удаления пустых профилей. Настоящий winws проверяет 66 комбинаций с `--dry-run`, включая `--wf-iface`. Изолированный sing-box без TUN проверяет реальные HTTP-запросы к тестовым серверам: дополнительные домены должны идти напрямую в обоих режимах маршрутизации.

Работающая пользовательская программа не заменялась, её VPN не отключался и настройки не изменялись. Новая сборка создаётся в отдельной папке. Второй настоящий WinDivert-перехватчик для сетевых экспериментов не запускался. Поэтому исправление проверено на уровне стратегии, маршрутизации и запуска, но воспроизведение YouTube и голос Discord с новой стратегией на данном провайдере пока не подтверждены.

Для последующей проверки пользователем: в новой сборке выбрать для YouTube и Discord «Через Zapret», сделать ALT10 активной и включить Zapret. Переключение маршрутов в текущей архитектуре пересоздаёт маршрутизатор; во время этой сессии оно намеренно не выполнялось. Запуск новой версии вместо старой также следует отложить до момента, когда краткий разрыв VPN допустим.

Семантика фильтров: [документация Zapret](https://github.com/bol-van/zapret/blob/master/docs/readme.md), [физический интерфейс WinDivert](https://github.com/bol-van/zapret/blob/master/docs/windows.md).

Итог проверки: 120/120 автоматических тестов, 66 сочетаний настоящим winws в режиме --dry-run. Сохранённый WinDivert-фильтр содержит ifIdx=24 (Ethernet) и исключает TUN с индексом 58. Готовая сборка прошла smoke-проверку с кодом 0, проверки переключения вкладок, прокрутки и применения правил в изолированной SOCKS-сессии без TUN. Проверены 9 компонентов и 330 SHA-256 файлов. Пользовательский NetCat PID 17048 и его sing-box PID 16068 продолжают работать; тестовые процессы завершены.
