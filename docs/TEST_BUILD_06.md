# Тестовый билд 06 — 0.5.0-test.6

Запуск: `artifacts/NetCat-Test-06/NetCat.exe`. Завершите предыдущую версию через трей. Установка и публикация релиза не нужны. Настройки остаются в зашифрованном хранилище пользователя.

## Соединения

- Trojan использует Xray при импорте, запуске и тестировании. Сохранённые Trojan/Reality-профили получают исправленный выбор ядра.
- Сохраняется начальный `/` gRPC serviceName: это пользовательский путь Xray, а не лишний разделитель. Ранее удаление `/` приводило к ответу 404 и ошибке TLS на клиенте. При первом запуске подписки перечитываются, старые пути сопоставляются с исходными без потери ID профиля, локального имени и участия в автосмене. Отдельные профили без сохранённой подписки с повреждённым путём нужно импортировать заново: угадывать потерянные данные программа не должна.
- Xray разрешает публичный адрес своего сервера через отдельный DoH-маршрут, привязанный к физическому IPv4. Это устраняет использование системного кеша с FakeIP от другого туннеля. Локальные серверы используют DNS физического адаптера. DNS-разрешение адреса VPN не зависит от самого VPN.
- UDP-сессии TUN разделяются по адресу и порту назначения; DNS-перехват ограничен портом 53. Требуется поставляемый sing-box 1.14.0 или новее.
- Смена выбранного профиля автоматически применяет его к работающему VPN. Быстрые последовательные выборы объединяются. Отключённый VPN от смены профиля не включается. Ошибка запуска сохраняет предыдущую рабочую конфигурацию.

## Интерфейс и маршрутизация

- Заголовок перемещается стандартным механизмом Windows; вкладки остаются клиентской областью и принимают нажатия.
- Два режима: «По правилам» — напрямую при отсутствии совпадений; «Весь трафик» — VPN при отсутствии совпадений. Явные правила работают в обоих режимах, включая прямые исключения. Старые выборочные режимы мигрируют в соответствующий новый режим.
- Приоритет: явные домены OpenVPN, пользовательские правила по порядку, корпоративные домены, встроенные правила сервисов в режиме «По правилам», локальные IP, маршрут по умолчанию. Встроенные правила сервисов пояснены на вкладке маршрутизации; правило пользователя может их переопределить. Имена типов и маршрутов переведены.
- Zapret: «Сделать активным» сохраняет конфигурацию для тумблера на главной. Выделение строки и временный запуск не меняют этот выбор. Зелёный фон означает успех всех HTTPS-проверок выбранного сценария; акцент выделения имеет приоритет. Автоматическое назначение лучшего конфига включается отдельной галочкой.
- Полоса оттенка принимает нажатие и перетаскивание в любой точке.

## Проверки

68 автоматических тестов, включая реальную смену маршрута между двумя локальными SOCKS-серверами с разными HTTP-ответами, отказ некорректной конфигурации, сохранение рабочего подключения, два режима маршрутизации, официальный валидатор Xray и восстановление gRPC-путей.

На исходных пользовательских подписках проверены 8 уникальных профилей дважды: все 16 HTTPS-запросов успешны. Проверки запускали отдельные ядра без изменения текущего TUN пользователя. Это подтверждает работу профилей в момент проверки, но не заменяет длительную проверку всего системного трафика, голоса Discord или корпоративной сети.

Проверены native hit-test заголовка HTCAPTION, всех семи вкладок HTCLIENT, переключение вкладок при двух ширинах окна, промежуточные кадры плавной прокрутки и снимки интерфейса.

Технические основания: [пользовательские пути gRPC в Xray](https://github.com/XTLS/Xray-core/blob/main/transport/internet/grpc/config.go), [DNS-разрешение исходящего соединения Xray](https://xtls.github.io/en/config/transports/sockopt.html), [UDP NAT sing-box](https://sing-box.sagernet.org/configuration/shared/udp-nat/).
