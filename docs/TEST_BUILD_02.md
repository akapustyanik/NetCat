# Проверка билда 02 — 12 сентября 2026

Исправления по обратной связи пользователя:

- Импорт XHTTP направляется в Xray, поддерживается Xray JSON. Reality также использует Xray. В личной подписке обнаружены четыре профиля, все приняты валидаторами ядер; Reality, WS и XHTTP прошли HTTP-запрос через отдельные тестовые процессы. Trojan/gRPC не прошёл проверку ни в одном из двух ядер. Ссылки, пароли и конфигурации пользователя не включены в репозиторий.
- Внешнее имя VPN-сервера больше не ожидает ответ неработающего DNS роутера: добавлен независимый DNS bootstrap через DoH физического адаптера. DNS корпоративных доменов не заменён публичным.
- Готовность ядра проверяется по PID владельца локального порта. Существующий сторонний listener больше не создаёт ложное состояние «VPN подключён». Конфликтный порт заменяется свободным для сессии с отображением адреса.
- Проверки профилей используют собственные процессы, порты и каталоги, отдельный семафор и отмену. Тест с намеренно зависшим SOCKS-handshake подтверждает, что команда отключения выполняется независимо. При фоновой автосмене повторно проверяется намерение пользователя и номер сессии.
- В официальных BAT обнаружены обращения к `*-user.txt`, отсутствующим до выполнения `service.bat`. NetCat не исполняет BAT: необязательные отсутствующие исключения пропускаются, список файлов проверен для всех комплектных стратегий и трёх сценариев.
- Telegram использует официальный Python CLI Flowseal, подтверждён запуск и остановка listener без импорта tray/GUI. Исходники проверены по Git blob-хешам, Python — по Authenticode, зависимости — по SHA-256 PyPI.
- Проверены обращения к официальным источникам всех шести модулей. Установка предлагается отдельно, совместимость OpenVPN ограничена веткой 2.6. Критичные проверки выполняются до замены текущих файлов, резерв доступен для отката.
- Нативные экраны и новые диалоги отрисованы в светлой и тёмной теме. Градиентная палитра, выбор приложений с иконками и карточки Zapret доступны без браузерной оболочки.

Подтверждено 37 автоматических тестов. Работа WinDivert на реальном трафике, корпоративный OpenVPN и корпоративные локальные сайты не подтверждены этой серией проверок. Тестовый билд не опубликован и не упакован в ZIP.
