# Тестовый билд 09 — геоданные

Версия: 0.5.0-test.9. Запуск: `artifacts/NetCat-Test-09/NetCat.exe`. ZIP не создаётся. Базы поставляются в `modules/geoip/geoip.dat` и `modules/geosite/geosite.dat`; пользовательские настройки остаются в прежнем хранилище.

## Что добавлено

- GeoIP и GeoSite как два независимых компонента центра обновлений. Автоматическая проверка при запуске и каждые 6 часов; ручная проверка; установка выбранных обновлений, закрепление и откат.
- Версии вида `202609122339` сравниваются как даты. Более старые базы не предлагаются вместо новых. Полный пакет содержит девять компонентов; каждый обновляется отдельно по своей версии.
- Правила GeoSite и GeoIP в простом редакторе, локализация типов, распознавание префиксов `geosite:` и `geoip:`. Категория проверяется до сохранения; отсутствующая база или категория дают понятную ошибку.
- GeoSite: точные домены, суффиксы, ключевые слова, регулярные выражения и атрибуты `@`. GeoIP: IPv4/IPv6-подсети. Выбранные категории преобразуются в нативные правила sing-box и применяются независимо от основного VPN-ядра, включая Xray. DNS для групп доменов следует выбранному маршруту. Правила не включаются автоматически после установки баз.
- Загрузка больших категорий при перестроении маршрутизатора выполняется вне UI-потока. Ошибка чтения проверяется до остановки действующего маршрутизатора.
- `scripts/Fetch-Geodata.ps1` скачивает базы для разработчика с проверкой GitHub SHA-256; общий скрипт модулей вызывает его автоматически. Полный тестовый билд включает файлы баз, источники и лицензию.

## Проверка

Новые тесты покрывают версии по датам, префиксы, типы доменов и атрибуты protobuf, обрезанные данные, отсутствующие категории, независимое обновление компонентов. Конфигурация с реальными `category-ru`, `category-ads-all` и `ru` проверяется установленным sing-box командой `check`.

Отдельная проверка реального ModuleUpdater скачала обе базы из выпуска `202609122339`, установила их, отклонила неправильный SHA-256 без повреждения установленного файла и восстановила предыдущую версию. В базах 260 категорий GeoIP и 1546 категорий GeoSite.

Итог: 87 тестов пройдены; готовый EXE запущен в режиме проверки интерфейса (код выхода 0), обе строки геоданных видны, прокрутка колёсиком над модулями проверена. Манифест готовой папки содержит девять компонентов.

Сетевая работа полного TUN на пользовательских профилях в этом изменении не проверялась. Наличие страны или домена в базе не гарантирует фактическую доступность сайта; проверка правила использует переданный домен/IP и не выполняет DNS-запрос за пользователя. Тестовая сборка остаётся без Authenticode-сертификата.
