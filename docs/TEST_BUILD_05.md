# NetCat 0.5.0-test.5

Запуск: `artifacts/NetCat-Test-05/NetCat.exe`. В корне только EXE, README и папки `modules`, `metadata`. Все библиотеки .NET включены в EXE; нативную часть среды .NET извлекает в собственный кеш при запуске. Переносите папку целиком. Профили и правила по-прежнему находятся в `%LOCALAPPDATA%/NetCat`, зашифрованы DPAPI и не входят в обновления.

## Исправления

- Тесты Zapret вынесены в отдельную операцию с явной кнопкой прерывания. «Остановить» также отменяет выполняющийся тест до ожидания блокировки. При отмене проверки восстанавливается прежняя стратегия; при команде остановки Zapret остаётся выключен. Прогресс больше не пересоздаёт строки списка.
- В режиме «Весь трафик» внешние сервисы идут через VPN, без исключения YouTube/Discord на Zapret и Telegram на внешний SOCKS5. Локальная сеть и явно назначенные домены OpenVPN сохраняются. В остальных режимах при недоступном внешнем SOCKS5 Telegram направляется через VPN с записью причины в журнал.
- Для Xray проверяется доступность порта одновременно TCP и UDP; прежняя проверка только TCP могла выбирать запрещённый/занятый UDP-порт.
- На главном экране тумблеры Zapret и WS proxy, подпись OpenVPN, дополнительный отступ над кнопкой VPN. Выбор запущенных приложений использует ту же плавную пиксельную прокрутку. Буквы в карточках обновлений удалены.
- Логотип `logo.png` встроен в значок EXE, окна и трей.

## Обновление NetCat

Центр проверяет семь компонентов, включая NetCat из `akapustyanik/NetCat`. Проверка при запуске, каждые 6 часов и вручную; установка начинается по команде пользователя, NetCat перезапускается после обновления.

Полный переносимый ZIP содержит `metadata/release-manifest.json`: версии компонентов и SHA-256 каждого принадлежащего им файла. После проверки SHA-256 архива и всех файлов строится план. Компоненты с равной/новее установленной версией и закреплённые компоненты пропускаются. Wintun отделён от sing-box, включая его копию DLL. Версии ранее отдельно обновлённых модулей учитываются.

Отдельный экземпляр текущего EXE выполняет замену после завершения основного процесса. Блокировка не даёт запустить приложение во время замены. Файлы сохраняются в `metadata/rollback`; при исключении уже заменённые файлы восстанавливаются. Результат — `metadata/last-update.txt`. Это откат ошибок операции, не гарантия восстановления при физическом сбое диска или выключении питания посреди обновления.

## Подпись Windows

На компьютере не обнаружен сертификат подписи кода в хранилищах пользователя и компьютера. Тестовый EXE не подписан. Подготовлен `scripts/Sign-Release.ps1`; производственная упаковка `scripts/Pack-Portable.ps1` требует доверенную подпись. После подписи заново создаются манифест и хеш ZIP. Подписанная версия принимает обновление только с доверенной подписью и тем же публичным ключом издателя. Смена ключа требует отдельно проверенного перехода.

Самоподписанный сертификат и удаление защитных меток не используются. Даже доверенная подпись не гарантирует отсутствие SmartScreen для нового приложения: нужна репутация издателя/файла. См. [документацию Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## Проверка

57 автоматических тестов: отмена зависшего HTTP-теста Zapret, план обновления без понижения версий и с закреплением, проверка файлов и опасных путей, восстановление файлов при ошибке обновления, регрессии маршрутизации и HTTP-пинга. Проверены single-file EXE, все вкладки, две ширины окна и официальные источники семи компонентов. На действующем пользовательском подключении обычные системные HTTPS-запросы к Google и Microsoft прошли; это не доказывает доступность каждого сайта, Telegram-сервера и всех импортированных профилей.

Проверена реальная замена EXE отдельным процессом из полного ZIP и запуск обновлённого EXE: программа перешла с тестового значения 0.4.0 на 0.5.0-test.5; Xray с тестовой более высокой версией 999.0.0 и закреплённый Zapret 0.1.0 остались без изменений. Проверены семь компонентов и 322 файла пакета.

Полный тестовый архив остаётся локальным, GitHub-релиз не публикуется.
