# Тестовый билд 08

Запуск: `artifacts/NetCat-Test-08/NetCat.exe`. Завершите предыдущую версию через трей. Архив и публичный релиз не создаются.

## Доступ и состояния

Главная страница различает отключение, подключение, проверку доступа, работу VPN, отсутствие доступа и автоматическое восстановление. Запуск ядра ещё не означает успешную проверку. Без TUN успешный тест обозначается как работа прокси.

Проверка профиля выполняется через отдельный локальный вход, связанный с активным VPN. Дополнительная проверка системного TUN отправляет HTTPS-запрос к `1.1.1.1` без системного HTTP-прокси: проверяется интерфейс маршрута Windows, TCP-сокет привязывается к адресу TUN и выделенному исходному порту. Только этот запрос направляется через служебное правило перед обходом процессов NetCat; пользовательские приложения сохраняют свои маршруты. HTTPS-сертификат проверяется штатно. Проверки выполняются в фоне, устаревший результат после смены подключения не применяется.

Проверка подтверждает доступ до тестового узла, а не доступность каждого сайта, всех корпоративных ресурсов или UDP. В текущем сеансе разработки полный запрос через Windows TUN не прогонялся: активного адаптера NetCat-TUN не было. Сгенерированное правило проверено официальным sing-box; запуск и интерфейс проверены без повышения прав и без изменения сети пользователя.

## Правила

Основная форма: домен/приложение/IP, значение и маршрут. Точный тип совпадения, TCP/UDP, порт и включение находятся в разделе «Дополнительно». Уже настроенные дополнительные условия раскрываются при редактировании. Полный путь приложения распознаётся автоматически. Скрытие раздела не сбрасывает условия.

## Переключение профилей

Перед заменой выполняется отдельный HTTP-тест кандидата. Старое подключение работает до окончания проверки. Неудача сохраняет старый профиль; ручная смена выбора и отключение VPN отменяют устаревшее переключение. Ядра тестов изолированы от рабочего ядра.

Автосмена требует минимум двух ошибок подряд у активного профиля, двух свежих успешных результатов кандидата и повторной проверки перед применением. Рейтинг опирается на медиану свежих успешных измерений. Между автоматическими переключениями выдерживается две минуты; один скачок задержки ничего не переключает. Выключение автосмены проверяется ещё раз непосредственно перед применением. Переключение всё ещё требует перезапуска маршрутизатора: существующие TCP-соединения могут переподключаться, бесшовное перенесение сокетов не заявляется.

## Результаты

Карточки профилей содержат короткий результат; кнопка «Подробности» показывает время проверки, ядро и техническое сообщение. Категория ошибки является объяснением наблюдаемого сбоя, а не гарантированным диагнозом настроек сервера.

Результаты Zapret сохраняются в зашифрованных настройках отдельно по конфигурации и сценарию YouTube/Discord. Кнопка «История проверок» показывает последние результаты каждого сценария; зелёное выделение относится к выбранному сценарию. Успешные проверки сохраняются и при отмене оставшейся части автотеста. HTTPS-тест не проверяет голос Discord и воспроизведение видео.

Проверки: автоматические регрессии для предварительного теста, сохранения старого соединения, запрета отключённой автосмены, накопления ошибок/успехов, паузы между переключениями, раздельной истории Zapret и служебного маршрута TUN; WPF smoke для вкладок, прокрутки и двух состояний редактора правил.

Источники: [условия маршрутизации sing-box](https://sing-box.sagernet.org/configuration/route/rule/), [GetBestInterface Windows](https://learn.microsoft.com/en-us/windows/win32/api/iphlpapi/nf-iphlpapi-getbestinterface).
