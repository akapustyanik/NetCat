# NetCat 1.0.1

- OpenVPN работает независимо от основного VPN: при включённом «VPN / TUN» корпоративные домены и DNS используют OpenVPN, обычный трафик идёт напрямую.
- При совместной работе основного VPN и OpenVPN используется один TUN. Без TUN OpenVPN сохраняет поддержку IP-маршрутов.
- После намеренного отключения OpenVPN корпоративные сайты снова обрабатываются обычными правилами маршрутизации.
- Исправлена очистка уже отсутствующих собственных маршрутов OpenVPN.
- Добавлены зависимости HTTP/2 для Telegram WS proxy 1.11 и исправлен вылет при подключении Telegram во время запуска или обновления proxy.

Проверки: 1598/1598 автоматических тестов; реальные DNS/TCP/HTTPS и переходы между режимами VPN в Windows 11 VM.

Скачайте ZIP, распакуйте в отдельную папку и запустите `NetCat.exe`. Существующие профили сохраняются; VPN-серверы не включены.

EXE не подписан Authenticode. Обновление приложения выполняется вручную; SHA256, Ed25519-манифест и проверки безопасности updater сохранены. OpenVPN остаётся версии 2.6.22.
