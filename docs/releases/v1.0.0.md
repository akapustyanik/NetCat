# NetCat 1.0.0

Первая официальная версия NetCat для Windows 10/11 x64.

- VPN-профили sing-box/Xray, TUN и правила маршрутизации.
- Проверки профилей, мониторинг и автоматическое переключение.
- OpenVPN, Zapret, Telegram WS proxy, подписки и обновление модулей.
- Восстановление трея после запуска Explorer и открытие окна одним щелчком.

Скачайте ZIP, распакуйте и запустите NetCat.exe. VPN-серверы не включены.
EXE не подписан Authenticode; обновление программы в этой версии выполняется вручную.
Подписи Ed25519, SHA256 и проверки updater сохранены.
Поддержка протокола не гарантирует доступность конкретного сервера или маршрута.
OpenVPN остаётся версии 2.6.22.
