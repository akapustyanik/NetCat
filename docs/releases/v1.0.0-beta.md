## NetCat 1.0.0-beta

Первая публичная beta-версия нового NetCat.

### Что есть в этой версии

- VPN через sing-box / Xray с поддержкой TUN.
- Маршрутизация по приложениям, доменам и сервисам.
- Zapret для YouTube и Discord одновременно с VPN.
- OpenVPN и Telegram WebSocket proxy.
- Проверка профилей и автоматическое переключение при сбоях.
- Обновление сетевых модулей и баз геоданных.

### Исправлено перед beta

- Исправлена маршрутизация Zapret при одновременно включённых VPN + TUN (Mode D).
- Устранён IPv6 blackhole на физических сетях без рабочего глобального IPv6.
- Исправлена обработка Discord Gateway и голосовых портов через direct + Zapret.
- Улучшено восстановление состояния VPN и надёжность транзакций настроек.

### Ограничения beta

- Приложение пока запускается с правами администратора.
- IPv6 через VPN не гарантируется, если физическая сеть не имеет рабочего глобального IPv6.
- Голосовой Discord в браузере следует правилам браузера, а не отдельному правилу Discord.
- Windows SmartScreen может показывать предупреждение для неподписанной beta-сборки (сверьте контрольную сумму SHA-256).
- Полное самообновление NetCat недоступно без доверенной цифровой подписи; обновление отдельных сетевых модулей работает штатно.
