NetCat 1.0.2

Updated October 10, 2026.

Changes:
- Fixed DNS transport recovery after temporary socket errors and port exhaustion.
- Fixed VPN monitoring restart after cancellation.
- Restored DNS and SOCKS listener operation after temporary TCP accept failures.
- Fixed asynchronous shutdown completion through the single-instance IPC channel.
- Made automatic profile tests and update checks work during hidden startup without an open window.
- Added Authenticode signing with the NetCat publisher certificate and explicit per-user certificate enrollment and removal.
- Added optional automatic application updates when connections and tests are stopped; all existing signature, publisher and rollback checks remain enabled.
- Fixed installation of prepared application updates: the helper verifies and extracts the archive into a fresh directory before applying it.

The Windows x64 package is self-contained. Its SHA256 checksum, Ed25519-signed manifest and public publisher certificate are included. The self-signed certificate must be explicitly trusted in Settings before enabling automatic updates. Users of unsigned 1.0.0/1.0.1 must install 1.0.2 manually once.
